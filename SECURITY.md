# Security Policy

## Supported Version

Security fixes are applied to the current main deployment of AgentProof.

## Reporting a Vulnerability

Please report suspected security issues privately to [support@agent-proof.dev](mailto:support@agent-proof.dev) with the subject line Security report: AgentProof.

Include, where possible:

- A clear description of the issue and its potential impact.
- Steps to reproduce using non-sensitive test data.
- Affected URL, API route, or component version.
- Any suggested mitigation.

Do not post unpatched vulnerabilities, secrets, user data, access tokens, endpoint credentials, or private reports in public GitHub issues.

## Response Expectations

We will acknowledge a valid report, investigate the impact, and coordinate a remediation timeline. Please allow reasonable time for a fix before disclosing details publicly.

## Security Scope

Relevant reports include authentication and authorization issues, owner-isolation failures, exposed credentials, insecure webhook handling, unsafe endpoint validation, SSRF bypasses, payment-entitlement errors, and evidence/report data exposure.
